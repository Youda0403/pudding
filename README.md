# 탱글 푸딩

동물 푸딩을 골라 만들고, 톡 누르면 뵤잉 흔들리고, 저장하면 한 바퀴 도는
GIF 가 받아지는 픽크루 사이트.

푸딩은 그림이 아니라 **거리장(SDF) 레이마칭**으로 매 프레임 계산한다.
그래서 어느 각도에서 봐도, 아무리 흔들려도 모서리가 생기지 않는다.

## 실행

정적 파일뿐이라 로컬에서는 간단한 정적 서버로 열면 된다.

```bash
npx http-server -p 8099 .
# http://127.0.0.1:8099/index.html
```

`proto/cat.html` 은 형태를 만질 때 쓰는 개발용 페이지다. 드래그로 시점,
`1` 완성 / `2` 정면 실루엣 / `3` 측면 실루엣, `Space` 흔들림,
`A` 동물 / `E` 눈 / `M` 입. 사이트와 **같은 셰이더 파일**을 읽으므로
한쪽만 고쳐져 모양이 갈라지는 일이 없다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` `styles.css` | 사이트 껍데기 |
| `js/app.js` | UI · 흔들림 · GIF 저장 |
| `js/sdf/shader.js` | GLSL 원본 (푸딩의 모든 형태와 색이 여기 있다) |
| `js/sdf/scene.js` | WebGL2 초기화와 유니폼 전달 |
| `js/gif.js` | GIF 인코더 (팔레트 + LZW, 외부 라이브러리 없음) |
| `js/color.js` | 색 유틸 |

`js/config.js` `js/state.js` `js/motion.js` `js/render.js` `js/main.js`
`js/parts/*` 는 Canvas 2D 로 그리던 예전 판이다. 사이트는 더 이상 쓰지 않고
그대로 남겨 두었다.

## 고를 수 있는 것

| | 값 |
| --- | --- |
| 동물 | 고양이 · 강아지 · 토끼 · 롭이어 · 곰 · 쥐 · 여우 · 햄스터 |
| 눈 | 동글 · 올라간 · 내려간 · 반 · 웃는 |
| 입 | ω · ^ · 一 · 웃는 |
| 꾸미기 | 시럽 웅덩이 · 체리 · 생크림 · 스프링클 (서로 배타적이지 않은 토글, 자유 조합) |
| 색 | 푸딩 · 눈 · 시럽 · 배경 (기본 색동그라미 + 직접 고르기) |

## 형태

자세한 이유는 `js/sdf/shader.js` 안의 주석에 있다. 요약만 적으면:

- 두 덩어리를 합칠 때 `min()` 을 쓰지 않는다. 전부 지수형 smooth min
  (`sminExp`) 이다. 다항식 계열은 영향 범위의 경계에서 곡률이 끊겨
  그 자리에 띠가 보인다.
- 몸통은 타원체 **하나**다. 덩어리를 여러 개 겹치면 교차선마다 외곽선
  기울기가 튀어서(단차) 아무리 뭉개도 남는다.
- 세운 귀(고양이·여우)는 밑동 구를 **몸통 타원에 접하는 직선** 위에 올린다.
  머리와 귀가 같은 직선에 접하면 이음매에서 기울기가 꺾일 수가 없다.
- 귀는 겉덩어리만으로는 '몸에 붙인 도형' 으로 보인다. 앞면에 귓바퀴를 파고
  안쪽에만 색을 얹어야 귀로 읽힌다.
- 얼굴 자국은 3D 도형을 얹어 파지 않는다. 정면에서 본 2D 모양을 기둥으로
  밀어낸 뒤 표면 껍질과 교집합해 새긴다. 볼이 휘어도 깊이가 일정하다.
- 시럽은 접시 위 웅덩이 하나로 정리했다. 처음엔 머리에도 부었는데,
  경계를 아무리 다듬어도(sin 물결 → 아래로 매달린 '혀') 흘러내림이
  진짜 액체로 안 보였다 — 결국 "얹혀서 굳은 것"과 "흘러 고인 것"은
  다른 문제였고, 후자만 접시에서 제대로 풀렸다.
- 접시 웅덩이는 형태를 만들지 않는다. 얕은 원반이라도 두께가 있으면
  가장자리에 반드시 테두리(모서리)가 생긴다. 그래서 지오메트리 자체를
  없앴다 — 접시 표면에 그 자리가 웅덩이 반경 안이면 커스터드에 칠하던
  것과 같은 Beer-Lambert 로 접시 색 위에 시럽색을 얇게 얹는다. 두께 0 인
  판이니 솟아오른 모서리가 있을 수 없고, 가장자리는 smoothstep 하나로
  사라진다. 법선 렌더로 봐도 접시는 완전한 평면이다.
- 토핑(체리·생크림)은 정수리(귀와 무관하게 sdBody 혼자 정하는 자리)에
  얹는다. 생크림이 '머리에서 자라난 혹' 이 아니라 '짤주머니로 짜서 톡
  올린 덩어리' 로 보이는 건 두 가지 덕이다. 하나, 몸통과 녹이는 k 가
  아주 작다(0.010) — 크게 두면 목이 두꺼워져 머리가 부푼 것처럼 보인다.
  둘, 코일이 보인다 — 반지름이 줄어드는 구를 나선 위에 늘어놓되 서로
  녹이는 k 를 작게(0.014) 둬서 구 사이의 골을 남긴다. 키우면 골이 메워져
  그냥 매끈한 원뿔이 된다.
- 스프링클은 정수리 자리가 좁아(귀 두 개가 조이는 자리) 생크림이나 귀가
  가까운 동물에서 다 먹혀서, `onFace()` 로 이마 위에 따로 흩뿌렸다.

## 화면

폰에서 쓰는 걸 기준으로 짰다. 예전엔 위에서 아래로 흐르는 문서였는데,
선택지를 고르려고 스크롤을 내리는 순간 푸딩이 화면 밖으로 나가 버려서
바꾼 결과를 볼 수가 없었다. 그래서 페이지 스크롤을 없애고 세로 세 칸으로
나눴다.

| 칸 | 동작 |
| --- | --- |
| 미리보기 | 고정. 늘 보인다 (세로가 짧으면 자동으로 작아진다) |
| 선택지 | 이 칸만 스크롤 |
| 랜덤 · GIF 저장 | 아래 고정. 엄지가 닿는 자리 |

누르는 것은 전부 최소 44px 로 잡았다. 색동그라미는 보이는 원이 30px 이고
나머지는 투명한 여백이다 — 원 크기 그대로 두면 옆 색이 눌린다.
색은 한 줄에 여섯 개까지만 둔다. 여덟 개를 두면 폰 가로폭에서 '직접
고르기' 가 다음 줄로 밀려 색 한 줄이 세 줄을 차지한다.

## 흔들림

셰이더는 높이의 제곱에 비례하는 전단 + 아주 약한 숨쉬기로 흔든다.
세기(`uJiggle`)와 시각(`uTime`)은 JS 가 준다.

- 누르면 시각이 0 으로 돌아가고 세기가 최대(3.5)가 됐다가 지수적으로 잦아든다.
  시각을 되돌리지 않으면 하필 sin 이 0 인 순간에 눌렸을 때 아무 일도
  안 일어난 것처럼 보인다.
- 가만히 두면 세기 0.1 로 미세하게 떤다.

## GIF

`js/gif.js` 하나로 만든다. 15비트 히스토그램 + median cut 으로 256색
팔레트를 잡고, 8×8 Bayer 로 약하게 흔든 뒤 LZW 로 압축한다. 모든 프레임이
같은 팔레트를 쓰므로 도는 동안 색이 깜빡이지 않는다.

기본값은 300×300 · 24프레임 · 60ms (한 바퀴 1.44초) · dither 2 → 약 500KB.
`js/app.js` 위쪽 상수 네 개로 바꾼다. dither 를 0 으로 두면 400KB 로 줄지만
배경 그라데이션에 동심원 띠가 보인다.

흔들림은 한 바퀴에 정확히 두 번 진동하도록 시각을 넣어 첫 프레임과 끝
프레임이 이어진다.
