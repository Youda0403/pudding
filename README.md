# 탱글 푸딩

동물 푸딩을 꾸미고, 톡 누르면 뾰잉 흔들리고, 회전 또는 제자리 흔들림 GIF로 저장하는 모바일 중심 사이트다.
HTML/CSS/JavaScript와 WebGL2 SDF 레이마칭만 사용한다. 서버·빌드·외부 런타임 라이브러리는 필요 없다.

## 실행

정적 서버에서 `index.html`을 연다. GIF Worker를 사용하므로 `file://` 대신 HTTP로 실행한다.

```sh
python3 -m http.server 8099
```

`proto/cat.html`은 같은 셰이더를 쓰는 개발 뷰어다. 드래그로 회전하고, 1/2/3으로 완성/정면/측면, Space로 흔들림, A/E/M으로 동물/눈/입을 바꾼다.

## 현재 선택지

| 항목 | 선택지 |
|---|---|
| 동물 | 고양이, 강아지, 토끼, 롭이어, 곰, 쥐, 여우, 햄스터 |
| 눈 | 동글, 올라간, 내려간, 반, 웃는 |
| 입 | ω, ^, 一, 웃는, 점, 활짝 |
| 꾸미기 | 시럽, 체리, 생크림, 스프링클 — 독립 토글 |
| 접시 | 기본, 꽃잎, 타원, 둥근 사각 — 흰 도자기 |
| 색 | 푸딩, 눈·입, 시럽, 배경 |
| GIF | 천천히 한 바퀴 / 제자리 뾰잉 |

## 파일과 데이터 흐름

- `index.html`, `styles.css`: 고정 미리보기, 스크롤되는 선택 패널, 고정 하단 버튼.
- `js/app.js`: scene 객체를 변경하는 UI, 터치/드래그, 애니메이션 시간, GIF 캡처.
- `js/sdf/scene.js`: WebGL2 프로그램과 유니폼. 기본값은 `SDF_DEFAULTS`.
- `js/sdf/shader.js`: 몸통·귀·얼굴·토핑·접시·시럽의 형태와 재질, 조명.
- `js/gif-worker.js`: UI를 막지 않는 별도 스레드에서 인코딩.
- `js/gif.js`: 공통 256색 팔레트, 8×8 Bayer 디더링, LZW GIF 인코더.
- `js/color.js`: HEX/RGB 유틸.
- `proto/cat.html`: 현재 개발 뷰어. `proto/sdf.html`은 독립적인 옛 실험 파일.

`js/config.js`, `state.js`, `motion.js`, `render.js`, `main.js`, `parts/*`는 현재 페이지가 사용하지 않는 예전 Canvas 2D 구현이다.
현재 코드를 바꾸려면 `js/sdf/*` 또는 `js/app.js`를 수정한다.

## 형태를 수정할 때

- 몸통은 타원체 하나를 유지한다. 구/원반을 덧대면 외곽선에 이음매가 생기기 쉽다.
- 몸통 앞뒤 비율의 변화는 C2 보간이다. 밑면 라운딩은 거리 보정 전에 계산해 흔들림 세기에 따라 밑동이 달라지지 않게 한다.
- 고양이·여우 귀와 몸통은 공통 접선 구조다. 곰·쥐의 둥근 귀는 구를 납작하게 변형하고, 나머지는 두 구의 볼록 껍질인 round cone을 쓴다.
- 귀를 납작하게 만든 만큼 거리도 보정한다. 귓바퀴는 앞쪽만 파며, 몸통을 합치기 전에 귀에서 파낸다.
- 눈·입은 2D 모양과 표면 껍질의 교집합으로 새긴다. 둘 다 `uInk`를 사용한다.
- 생크림은 겹친 구 대신 6개 골이 비틀리며 올라가는 하나의 둥근 원뿔이다. 밑동 반지름 0.190, 높이 약 0.30.
- 체리 반지름은 0.073. 생크림에 따라 중심 위치가 바뀐다.
- 스프링클은 항상 이마에 6개, 생크림이 있으면 크림에 5개를 추가한다. 이마 좌표는 동물별 실제 표면에서 법선 방향으로 띄워 계산한 상수 배열 `SPR_A/B`다. 몸통·귀·크림 형태를 변경하면 스프링클 좌표도 재검토한다.
- 시럽은 접시 위에 약간 볼록하게 고인 얇은 입체다. 표면 높이는 가운데 0.034, 가장자리 0.010. 짙은 색, 표면 반사, 길쭉한 조명 반사로 농도와 윤기를 표현한다. 실제 유체 시뮬레이션은 아니다.
- 접시 외곽은 `plateOutline`, 두께와 림은 `sdPlate`가 담당한다.

## 모바일 성능과 처음 뜨는 동작

- 처음에는 정지 상태로 나타난다. 터치한 뒤의 경과 시간은 `performance.now()`에서 계산하고 음수가 되지 않도록 한다.
- 가만히 있을 때는 WebGL로 다시 그리지 않는다. 동작 중 목표는 최대 30fps다.
- 미리보기는 최대 360px, DPR 최대 1.25. 느린 프레임이 반복되면 40px씩 내려 최저 200px까지 조절한다. GIF는 별도의 고정 300px다.
- 매 프레임의 `gl.finish()`를 없앴다. 저장은 draw 직후 같은 작업에서 캡처한다.
- 장면 바깥 빈 공간은 건너뛰며, 그림자/AO/반투명 근사에는 작은 얼굴 홈·스프링클을 반복 계산하지 않는다. 귀 안쪽은 자기 그림자가 잘못 생기지 않도록 유지한다.
- 실제 기기 GPU와 브라우저에 따라 성능은 달라진다.

## GIF

- 회전: 300×300, 60프레임 × 80ms = 4.8초, 360도 무한 루프.
- 제자리 뾰잉: 300×300, 40프레임 × 80ms = 3.2초. 터치와 같은 감쇠 동작 후 짧은 쉼.
- 별도 scene에 설정을 복사한 뒤 모든 조작을 잠그고 캡처한다. 촬영 중 다른 외형이 섞이지 않는다.
- 전 프레임 공통 팔레트, dither=2. 인코딩은 Worker에서 수행하며 완료·실패 모두 UI를 복원한다.
- 결과물은 `tangle-pudding-rotate.gif` 또는 `tangle-pudding-bounce.gif`로 받는다.

## 범위

URL 공유는 사용자 요청으로 계획에서 제외했다. 접시 색 선택 대신 흰색 접시 디자인을 선택한다.
글씨 넣기는 이번 변경 범위에 포함되지 않았다.
