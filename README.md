# 탱글 푸딩

동물 푸딩을 부위별로 골라 만들고, 탱글탱글 흔들리는 GIF를 만드는 픽크루 사이트.
사진 업로드 없이, 모든 부위를 Canvas 2D 경로로 그린다.

## 실행

정적 파일뿐이라 로컬에서는 간단한 정적 서버로 열면 된다.

```bash
npx http-server -p 8099 .
# http://127.0.0.1:8099/index.html
```

`?debug=1` 을 붙이면 좌표 기준점(눈·귀·꼬리·글씨 위치)을 화면에 표시한다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/config.js` | 캔버스 크기, 몸통 치수, 모든 부위가 공유하는 기준점 |
| `js/color.js` | 본체 색에서 밝기/그림자 색을 파생시키는 유틸 |
| `js/state.js` | 캐릭터 상태 객체 (UI는 이것만 바꾼다) |
| `js/parts/*.js` | 부위별 `draw...(ctx, state)` 함수 |
| `js/motion.js` | 움직임 정의(대기/탱글)와 프레임별 변형값 `poseFor` |
| `js/render.js` | 한 프레임 그리기. 미리보기와 GIF가 함께 쓴다 |
| `js/main.js` | 캔버스 초기화 |

## 부위 선택지

| 부위 | 값 |
| --- | --- |
| 눈 `eyes` | `round` `sparkle` `smile` `sleepy` `upturned`(올라간) `downturned`(내려간) `half`(반 눈) |
| | 올라간/내려간/반 눈은 `round`와 같은 원(r=8)을 각도만 다르게 직선으로 잘라낸 모양 |
| 눈 색 `eyeColor` | 자유 색. 기본 목록은 `PUDDING.EYE_COLORS` |
| 입 `mouth` | `three`(ω) `caret`(^) `dot`(.) |
| 시럽 `syrup` | `caramel` `choco` `strawberry` (고른 종류) |
| 시럽 색 `syrupColor` | 자유 색. 기본 목록은 `PUDDING.SYRUP_COLORS` (8색). 어두운 색은 여기서 파생 |
| 시럽 모양 `syrupShape` | `drip`(길게 흘러내림) `pool`(짧고 둥글게) |

깜빡일 때는 눈 종류와 상관없이 납작한 선으로 대체된다.

자른 눈 세 종류의 각도와 자르는 위치는 참고 이미지의 알파 마스크에
원+직선 모델을 픽셀 단위로 피팅해서 구했다.

| | 자르는 각도 | 중심에서 선까지 |
| --- | --- | --- |
| 올라간 | +16° (안쪽 위) | 0.712·r |
| 내려간 | −22° (바깥쪽 위) | 0.765·r |
| 반 눈 | 0° (수평) | 0.5·r |

## 움직임

모든 움직임은 프레임 번호 `f`와 전체 프레임 수 `N`만으로 계산한다(`t = f / N`).
미리보기와 GIF가 같은 `poseFor()` 값을 쓰기 때문에 화면에서 본 느낌이 그대로 GIF가 된다.

| 움직임 | 프레임 | 간격 | 내용 |
| --- | --- | --- | --- |
| `idle` | 60 | 50ms | 숨 쉬듯 말랑거림 + 루프당 한 번 눈 깜빡임 |
| `jiggle` | 60 | 40ms | 톡 쳤을 때의 감쇠 진동, 뒤쪽 20%는 정지 |

변형은 `{ skewX, scaleX, scaleY, blink }` 하나로 표현하고, 바닥 중심을 고정한 채
`ctx.transform`으로 적용한다. 접시와 그림자는 변형되지 않는다.
`delay`는 GIF가 10ms 단위로만 저장하므로 10의 배수로 둔다.

좌표는 **푸딩 바닥 타원의 중심**을 원점으로 한다. 눈·시럽·글씨는 몸통 종류와
관계없이 `PUDDING.ANCHOR` 기준점에 맞춰 그리기 때문에 부위를 늘려도 위치가
어긋나지 않는다.
